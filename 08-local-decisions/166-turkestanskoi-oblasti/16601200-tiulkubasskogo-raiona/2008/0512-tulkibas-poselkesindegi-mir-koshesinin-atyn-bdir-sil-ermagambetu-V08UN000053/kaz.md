# Түлкібас поселкесіндегі "Мир" көшесінің атын "Әбдірәсіл Ермағамбетұлы" атымен өзгерту туралы

Қазақстан Республикасының 08.12.1993 жылғы N 4200 "Қазақстан Республикасының әкімшілік-аумақтық құрылысы туралы" Заңының 14 бабының 4 тармақшасына сәйкес ШЕШІМ ЕТЕМІН:

<a id="para_1"></a>

1. Түлкібас поселкесіндегі "Мир" көшесінің атын "Әбдірәсіл Ермағамбетұлы" атындағы көше болып өзгертілсін.

<a id="para_2"></a>

2. Осы шешім ресми жарияланғаннан кейін күнтізбелік он күн өткен соң қолданысқа енгізілсін.

<a id="para_3"></a>

3. Осы шешімнің орындалуын Түлкібас поселке әкімі аппаратының бас маманы Ф. Ильясоваға жүктелсін.

**Түлкібас поселке әкімі**

**Қ. Ахметов**
