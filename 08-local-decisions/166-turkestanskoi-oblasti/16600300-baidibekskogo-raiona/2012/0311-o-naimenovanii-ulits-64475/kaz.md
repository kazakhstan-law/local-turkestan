# Көшелерге атау беру туралы

"Қазақстан Республикасындағы жергілікті мемлекеттік басқару және өзін-өзі басқару туралы" 2001 жылғы 23 қаңтардағы Қазақстан Республикасының Заңының 37 бабының 3-тармағына, "Қазақстан Республикасының әкімшілік - аумақтық құрылысы туралы" 1993 жылғы 8 желтоқсандағы Қазақстан Республикасының Заңының 14-бабының 4) тармақшасына сәйкес және Жамбыл ауылдық округі тұрғындарының пiкiрiн ескере отырып, Жамбыл ауылдық округінің әкімі ШЕШТІ:

<a id="p1"></a>

1. Жамбыл ауылындағы атауы жоқ көшелерге мынадай атаулар берілсін:

   солтүстік бөлігінде орналасқан көшеге – "Тәуелсіздік" атауы;

   оңтүстік бөлігінде орналасқан көшеге – "Жағалау" атауы.

<a id="p2"></a>

2. Шыбыт ауылындағы оңтүстік бөлігінде орналасқан атауы жоқ көшеге "Шапағат" атауы берілсін.

<a id="p3"></a>

3. Қызылжар ауылындағы оңтүстік бөлігінде орналасқан атауы жоқ көшеге "Жауқазын" атауы берілсін.

<a id="p4"></a>

4. Осы шешімнің орындалуын бақылауды өзіме қалдырамын.

<a id="p5"></a>

5. Осы шешім алғаш ресми жарияланғаннан кейiн күнтiзбелiк он күн өткен соң қолданысқа енгiзiледi.

**Ауылдық округінің әкімі:**
