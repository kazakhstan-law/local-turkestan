# Түлкібас поселкесінің көшелерінің атауларын өзгерту туралы

Қазақстан Республикасының 2001 жылғы 23 қаңтардағы «Қазақстан Республикасындағы жергілікті мемлекеттік басқару және өзін-өзі басқару туралы» Заңының 37-бабының 3 тармағына және Қазақстан Республикасының 1993 жылғы 8 желтоқсандағы «Қазақстан Республикасының әкімшілік-аумақтық құрылысы туралы» Заңының 14-бабының 4) тармақшасына сәйкес және тиісті аумақ халқының пікірін ескере отырып Оңтүстік Қазақстан облысы Түлкібас ауданы Түлкібас поселкесінің әкімі ШЕШТІ:

Түлкібас поселкесіндегі мына көшелердің атаулары өзгертілсін:

<a id="p1"></a>

1. «С.М.Киров» көшесін «Бекқожа Аблаев» көшесіне;

<a id="p2"></a>

2. «Железнодорожный» көшесін «Өнгенбай Сергенов» көшесіне.

<a id="p3"></a>

3. Осы шешімнің орындалуын бақылауды өз құзыретіме қалдырамын.

<a id="p4"></a>

4. Осы шешім алғаш ресми жариялағаннан кейін күнтізбелік он күн өткен соң қолданысқа енгізіледі.

**Поселке әкімі**

**Ж.Ботбаев**
