# Білім беру саласында білім алушыларды қоғамдық көліктерде жеңілдікпен тасымалдау туралы

Қазақстан Республикасының «Қазақстан Республикасындағы жергілікті мемлекеттік басқару туралы» Заңының 6-бабына, «Білім туралы» Заңының 31-бабының 1-тармағының 3) тармақшасына, 36-бабының 4-тармағының 1) тармақшасына сәйкес қалалық мәслихаты ШЕШТІ :

<a id="p1"></a>

1. Білім беру саласында білім алушылар қоғамдық көлікте (такси көлігінен басқа) жеңілдікпен тасымалдансын.

<a id="p2"></a>

2. Тиісті жылдың жол ақысына байланысты маршрут және автобус көлігінде тасымалдауға 50 пайыз жеңілдігі орнатылсын.

<a id="p3"></a>

3. Білім алушылардың тұратын мекен-жайы жеңілдікпен тасымалдау үшін оқу орнынан 3 км қашықтықта орналасуы қажет.

<a id="p4"></a>

4. Шешім әділет басқармасында тіркеліп, ресми жариялаған күннен бастап қолданысқа енгізілсін.

**С. Күнтуаров**
