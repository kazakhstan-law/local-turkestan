# Об утверждении плана по управлению пастбищами и их использованию по Сайрамскому району на 2025-2029 годы

В соответствии с подпунктом 15) пункта 1 статьи 6 Закона Республики Казахстан «О местном государственном управлении и самоуправлении» и подпунктом 1) статьи 8 Закона Республики Казахстан «О пастбищах» Сайрамкий районный маслихат РЕШИЛ:

1. Утвердить план по управлению пастбищами и их использованию по Сайрамскому району на 2025-2029 годы согласно приложению к настоящему решению.

2. Настоящее решение вводится в действие по истечении десяти календарных дней после дня его первого официального опубликования.

**Председатель Сайрамского районного маслихата**

**Ш.Халмурадов**


## Части документа

Документ разбит на части: целиком он слишком велик, чтобы GitHub его показал.
Каждая часть — это отдельный файл рядом с этим, и вместе они составляют полный
текст редакции.

| Часть | Название |
|---|---|
| [`part001`](rus/part001.md) | План по управлению пастбищами и их использованию в Сайрамском районе на 2025-2029 годы |
| [`part003`](rus/part003.md) | Сведения геоботанического обследования пастбищ |
| [`part003-t001-r001`](rus/part003-t001-r001.md) | `!` таблица 1, строки 1–255 |
| [`part003-t001-r002`](rus/part003-t001-r002.md) | таблица 1, строки 256–437 |
| [`part004`](rus/part004.md) | Сведения об объектах пастбищной инфраструктуры и о сервитутах для прогона сельскохозяйственных животных |

Части, помеченные `!`, всё равно превышают лимит. Таблицы разрезаны по строкам,
но разрез ставится только там, где через него не проходит ячейка с `rowspan` —
иначе она перестала бы относиться к своим строкам. Если такого места нет, или
одна строка сама по себе больше лимита, часть остаётся целой. Её видно в `Raw`
и в клоне репозитория.
