# Сайрам ауданы бойынша 2025-2029 жылдарға арналған жайылымдарды басқару және оларды пайдалану жөніндегі жоспарды бекіту туралы

«Қазақстан Республикасындағы жергілікті мемлекеттік басқару және өзін-өзі басқару туралы» Қазақстан Республикасың Заңының 6-бабының 1-тармағының 15) тармақшасына және «Жайылымдар туралы» Қазақстан Республикасы Заңының 8-бабының 1) тармақшасына сәйкес, Сайрам аудандық мәслихаты ШЕШІМ ҚАБЫЛДАДЫ:

1. Осы шешімнің қосымшасына сәйкес Сайрам ауданы бойынша 2025-2029 жылдарға арналған жайылымдарды басқару және оларды пайдалану жөніндегі жоспары бекітілсін.

2. Осы шешім алғашқы ресми жарияланған күнінен кейін күнтізбелік он күн өткен соң қолданысқа енгізіледі.

**Сайрам аудандық мәслихатының төрағасы**

**Ш.Халмурадов**


## Части документа

Документ разбит на части: целиком он слишком велик, чтобы GitHub его показал.
Каждая часть — это отдельный файл рядом с этим, и вместе они составляют полный
текст редакции.

| Часть | Название |
|---|---|
| [`part001`](kaz/part001.md) | Сайрам ауданы бойынша 2025-2029 жылдарға арналған жайылымдарды басқару және оларды пайдалану жөніндегі жоспары |
| [`part001-part003`](kaz/part001-part003.md) | Жайылымдарды геоботаникалық зерттеп-қарау мәліметтері |
| [`part001-part003-t001-r001`](kaz/part001-part003-t001-r001.md) | `!` таблица 1, строки 1–253 |
| [`part001-part003-t001-r002`](kaz/part001-part003-t001-r002.md) | таблица 1, строки 254–437 |
| [`part002`](kaz/part002.md) | Жайылымдық инфрақұрылым объектілері туралы және ауыл шаруашылығы жануарларын айдап өтуге арналған сервитуттар туралы мәліметтер |

Части, помеченные `!`, всё равно превышают лимит. Таблицы разрезаны по строкам,
но разрез ставится только там, где через него не проходит ячейка с `rowspan` —
иначе она перестала бы относиться к своим строкам. Если такого места нет, или
одна строка сама по себе больше лимита, часть остаётся целой. Её видно в `Raw`
и в клоне репозитория.
