# Жергiлiктi ауқымдағы табиғи сипаттағы төтенше жағдай жариялау туралы

«Қазақстан Республикасындағы жергiлiктi мемлекеттiк басқару және өзiн-өзi басқару туралы» Қазақстан Республикасының 2001 жылғы 23 қаңтардағы Заңының 33 бабының 1 тармағының 13) тармақшасына, «Азаматтық қорғау туралы» Қазақстан Республикасының 2014 жылғы 11 сәуiрдегi Заңының 48 бабына, Қазақстан Республикасы Үкiметiнiң 2014 жылғы 2 шiлдедегi №756 «Табиғи және техногендiк сипаттағы төтенше жағдайлардың сыныптамасын белгiлеу туралы» қаулысына сәйкес және Сайрам ауданының төтенше жағдайлардың алдын алу және жою жөнiндегi комиссиясының кезектен тыс отырысының 2017 жылғы 23 тамыздағы №6 хаттамасы негiзiнде, Сайрам ауданының әкiмi ШЕШIМ ЕТЕДI:

<a id="p1"></a>

1. Сайрам ауданы Қарамұрт ауылдық округінің 117 кварталында Ақсу өзені бойында орналасқан сібір жарасы көміндісін су шаюы қаупі туындауы мүмкiндігіне байланысты жергiлiктi ауқымдағы табиғи сипаттағы төтенше жағдай жариялансын.

<a id="p2"></a>

2. «Сайрам ауданы әкiмiнiң аппараты» мемлекеттiк мекемесi Қазақстан Республикасының заңнамалық актiлерiнде белгiленген тәртiпте:

   1) осы шешімді Сайрам ауданының аумағында таратылатын мерзімді баспа басылымдарында ресми жариялануын, сондай-ақ Қазақстан Республикасы нормативтік құқықтық актілерінің эталондық бақылау банкіне енгізу үшін Республикалық құқықтық ақпарат орталығына жіберуін;

   2) осы шешімді Сайрам ауданы әкiмдiгiнiң интернет-ресурсына орналастыруын қамтамасыз етсiн.

<a id="p3"></a>

3. Төтенше жағдайды жою басшысы болып Сайрам ауданы әкімінің кеңесшісі И.Марин тағайындалсын және осы шешімнен туындайтын тиісті іс-шараларды жүргізу тапсырылсын.

<a id="p4"></a>

4. Осы шешiмнiң орындалуын бақылауды өзіме қалдырамын.

<a id="p5"></a>

5. Осы шешiм алғашқы ресми жарияланған күнiнен бастап қолданысқа енгiзiледi.

**Аудан әкімі**

**Б.Мамаев**
