# Созақ ауданының аумағында сайлау учаскелерін құру туралы

«Қазақстан Республикасындағы сайлау туралы» Қазақстан Республикасының 1995 жылғы 28 қыркүйектегі Конституциялық заңының 23 бабының 1 тармағына және «Қазақстан Республикасындағы жергілікті мемлекеттік басқару және өзін-өзі басқару туралы» Қазақстан Республикасының 2001 жылғы 23 қаңтардағы Заңының 33 бабының 2 тармағына сәйкес Созақ ауданы әкімі ШЕШІМ ҚАБЫЛДАДЫ:

1. Созақ ауданының аумағында сайлау учаскелері осы шешімнің қосымшасына сәйкес құрылсын.

2. Созақ ауданы әкімінің 2012 жылғы 28 тамыздағы №35 «Созақ ауданының аумағында сайлау учаскелерін құру туралы» (Нормативтік құқықтық актілерді мемлекеттік тіркеу тізілімінде №2098 тіркелген, 2012 жылғы 8 қыркүйектегі аудандық «Созақ үні» газетінде жарияланған) шешімінің күші жойылды деп танылсын.

3. Осы шешімнің орындалуын бақылау аудан әкімі аппаратының басшысы Қ.Оразовқа жүктелсін.

4. Осы шешім оның алғашқы ресми жарияланған күнінен кейін қолданысқа енгізіледі.
